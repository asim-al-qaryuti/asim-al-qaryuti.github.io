# مكتبة الشيخ عاصم القريوتي

موقع ثابت (HTML + CSS + JavaScript) بلا أدوات بناء، يعمل على GitHub Pages مباشرة.

## الملفات

| الملف | ما فيه |
|---|---|
| `data/content.js` | **كل المحتوى**: الاسم، السيرة الذاتية، **الكتب** (`works` — انظر «الكتب وملفاتها» أدناه)، الحسابات |
| `data/articles.js` | **المقالات**: ما كتبه الشيخ بنفسه، مصنفًا حسب الموضوع (`cats`) |
| `books/` | ملفات الكتب (PDF) التي تُقرأ داخل الموقع |
| `data/json/` | **يُولَّد آليًا — لا تعدّله**: نسخة JSON من المحتوى لتطبيق الجوال (انظر «ملفات JSON لتطبيق الجوال») |
| `docs/data-format.md` | توثيق صيغة ملفات JSON |
| `tools/` | أداتا التحديث الآلي: جلب يوتيوب (`update_youtube.py`) وتوليد JSON (`build_json.mjs`) |
| `index.html` | هيكل الصفحة |
| `assets/css/style.css` | التصميم والألوان |
| `assets/js/app.js` | الصفحات والتبويبات والبحث والمشهد المرسوم في الواجهة |
| `assets/js/cv3d.js` | السيرة الذاتية ثلاثية الأبعاد (Three.js) |

## النشر على GitHub Pages (مرة واحدة)

1. ادخل https://github.com وسجّل الدخول (أو أنشئ حسابًا مجانيًا).
2. من الزر **+** أعلى الصفحة ← **New repository**.
   - الاسم: `qaryuti` (أو أي اسم إنجليزي قصير)
   - اختر **Public** ← **Create repository**.
3. في الصفحة التالية اضغط **uploading an existing file**.
4. افتح مجلد الموقع على جهازك، وحدد: `index.html` و`assets` و`data` و`README.md`، واسحبها كلها إلى صفحة الرفع ← **Commit changes**.
5. من تبويب **Settings** ← **Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main** و **/(root)** ← **Save**.
6. بعد دقيقة يصبح الموقع على الرابط الثابت:
   `https://اسم-حسابك.github.io/qaryuti/`

> إن سمّيت المستودع `اسم-حسابك.github.io` يصبح الرابط بلا لاحقة: `https://اسم-حسابك.github.io/`

### تحديث المحتوى لاحقًا
افتح المستودع ← `data` ← `content.js` ← أيقونة القلم ✏️ ← عدّل ← **Commit changes**. يتحدث الموقع خلال دقيقة.

## مقاطع يوتيوب (تلقائي)

- `data/youtube.js` يُولَّد تلقائيًا من قناة الشيخ https://www.youtube.com/@alqaryoti — لا تعدّله يدويًا.
- `.github/workflows/youtube.yml` يشغّل `tools/update_youtube.py` كل 6 ساعات، فيضيف المقاطع الجديدة ويعيد نشر الموقع.
- `data/youtube-rules.json` هو ما تعدّله:
  - `exclude`: معرّفات مقاطع لا تظهر أبدًا (ليست للشيخ).
  - `hold`: مقاطع مخفية حتى تُراجَع؛ انقل المعرّف إلى `include` لإظهاره.
  - `series`: البرامج وشروح الكتب المرئية — كل واحد بقوائم تشغيله أو كلمات من عناوين حلقاته. ما نوعه `book` يظهر في «البرامج» تحت «شروح الكتب»، والدورات تظهر مع البرامج.
  - المقاطع الجديدة التي يدل عنوانها أو وصفها على متكلم آخر («لفضيلة الشيخ فلان»، «قصيدة»، «تلاوة»...) تُستبعد تلقائيًا.
- **قنوات أخرى** (`external` في الملف نفسه): يبحث التحديث أيضًا باسم الشيخ في يوتيوب وفي قنوات مثل «مصابيح الأمل» و«كنوز العلم» و«مركز الإمام الألباني»:
  - يُقبل المقطع إن كان اسم الشيخ في عنوانه، ولم يكن مقطعًا **عنه** أو لقاءً مشتركًا مع غيره (`about_patterns`).
  - يظهر إن كان درسًا أو محاضرة (١٥ دقيقة فأكثر)، أو حلقة من برنامج أو كتاب مسجّل في `series` بالعلامة `"ext": true`.
  - المكرر مع قناة الشيخ يُتجاهل تلقائيًا، ويظهر تحت كل مقطع اسم القناة التي نُشر فيها.
  - لإخفاء مقطع معيّن ضع معرّفه في `exclude`، ولتجاهل قناة كاملة أضف اسمها إلى `exclude_channels`.
- معرّف المقطع هو ما بعد `v=` في رابطه، مثل `tk3Y1XFG37w`.
- لتشغيل التحديث يدويًا: تبويب **Actions** في المستودع ← «تحديث يوتيوب ونشر الموقع» ← **Run workflow**.

## المقالات

- `data/articles.js` فيه مقالات الشيخ من موقعه القديم alqaryooti.com (محفوظ في أرشيف الإنترنت) ومن حسابه في إكس — **ما كتبه بنفسه فقط**، بلا منقولات.
- كل مقال: `{ id, t: العنوان, cat: التصنيف, d: التاريخ (اختياري), src: المصدر, b: [الفقرات] }`. الفقرة التي تبدأ بـ `## ` عنوان فرعي، و`> ` اقتباس.
- لإضافة مقال: انسخ آخر مقال في القائمة وغيّر `id` إلى معرّف جديد، واختر `cat` من التصنيفات الموجودة.

## الكتب وملفاتها

كل كتاب في `works` داخل `data/content.js` بهذا الشكل:

```js
{ id: "w39", title: "قطف الثمر في بيان عقيدة أهل الأثر", type: "تحقيق", note: "لصديق حسن خان", href: "books/qatf-althamar.pdf" }
```

- `id`: **معرّف ثابت لا يُغيَّر أبدًا** — منه رابط قراءة الكتاب `#/read/w39`، ويحفظه تطبيق الجوال. للكتاب الجديد اختر معرّفًا إنجليزيًا قصيرًا غير مستعمل (مثل `kawkaba`)، ولا تعِد ترقيم الكتب القديمة.
- `type`: `تأليف` أو `بحث محكّم` أو `تحقيق` أو `تقديم ومراجعة`.
- `href` (اختياري): **ملف الكتاب**. إن وُجد ظهر زر «اقرأه» ويُفتح الكتاب داخل الموقع. يقبل:
  - مسارًا داخل المستودع: `"books/qatf-althamar.pdf"` (ارفع الملف إلى مجلد `books`)؛
  - أو رابطًا كاملًا في مكان آخر: `"https://books.example.com/qatf-althamar.pdf"`.

### لماذا قد تُنقل الكتب خارج المستودع

GitHub لا يقبل ملفًا أكبر من 100 م.ب (والرفع من صفحة الموقع حدّه 25 م.ب)، ويُفضَّل ألا يتجاوز المستودع 1 غ.ب، ولـ GitHub Pages حد شهري تقريبي للتنزيل قدره 100 غ.ب. يكفي هذا لعدد محدود من الكتب. إن كثرت الكتب أو كبرت، تُنقل إلى **Cloudflare R2** (تخزين رخيص بلا رسوم على التنزيل) بتغيير `href` فقط، دون أي تعديل في الموقع أو التطبيق.

### نقل كتاب إلى Cloudflare R2

1. في لوحة Cloudflare ← **R2 Object Storage** ← **Create bucket**، وسمّه مثلًا `qaryuti-books` (مرة واحدة).
2. افتح المخزن ← **Upload** ← ارفع ملف الكتاب (مثل `qatf-althamar.pdf`). تأكد أن نوع الملف `application/pdf`.
3. اجعل المخزن عامًا (مرة واحدة) من **Settings** ← **Public access**:
   - الأفضل: **Custom Domains** ← اربط نطاقًا فرعيًا تملكه مثل `books.example.com`؛
   - أو للتجربة فقط: فعّل **r2.dev subdomain** (سرعته محدودة، ولا يُنصح به للاستخدام الدائم).
4. انسخ رابط الملف العام، مثل `https://books.example.com/qatf-althamar.pdf`، وافتحه في المتصفح للتأكد أنه يعرض الكتاب.
5. في `data/content.js` غيّر `href` لهذا الكتاب إلى الرابط الكامل، واحفظ (Commit). لا تغيّر `id`.
6. بعد دقائق افتح صفحة الكتاب في الموقع وتأكد أنه يُقرأ، ثم احذف الملف القديم من مجلد `books` في المستودع.

ملاحظات:
- لا تضع على الملف في R2 ترويسة `Content-Disposition: attachment`، وإلا نزل الكتاب بدل أن يُعرض داخل الموقع.
- زر «تنزيل الكتاب» في الموقع يفتح الملف من R2 في نافذة المتصفح بدل حفظه مباشرة؛ ومنها يحفظه القارئ.
- أداة توليد JSON تتحقق من وجود الملفات داخل `books` فقط؛ أما الروابط الخارجية فتحقق منها بنفسك (الخطوة 4).

## ملفات JSON لتطبيق الجوال

- `data/json/` فيه `content.json` و`articles.json` و`youtube.json` و`index.json`، تُولَّد **آليًا** من `content.js` و`articles.js` و`youtube.js` بالأداة `tools/build_json.mjs`. **المصدر يبقى ملفات `.js` التي تعدّلها بيدك؛ لا تعدّل ملفات JSON.**
- تُحدَّث في سير العمل نفسه (`.github/workflows/youtube.yml`): كل 6 ساعات، وبعد كل رفع إلى المستودع.
- إن كان في البيانات خطأ (ملف معطوب، معرّف ناقص أو مكرر، ملف كتاب غير موجود) يتوقف النشر ويبقى الموقع الحالي كما هو، ويصلك بريد من GitHub. سبب الخطأ مكتوب بالعربية في سجل التشغيل: تبويب **Actions** ← آخر تشغيل ← خطوة «توليد ملفات JSON».
- الصيغة وكل الحقول موثقة في [`docs/data-format.md`](docs/data-format.md). الروابط: `https://asim-al-qaryuti.github.io/data/json/index.json` وأخواته.

## تطبيق الجوال

- التطبيق سيكون **تطبيقًا أصليًا** (Flutter) يقرأ ملفات JSON أعلاه ويعرض المحتوى بواجهته الخاصة؛ ويشغّل المقاطع بمشغّل يوتيوب الرسمي، ويفتح الكتب من `href`.
- ⚠️ **لا يُغلَّف هذا الموقع تطبيقًا لـ iOS** (أي تطبيق لا يفعل إلا عرض الموقع داخل إطار WebView): أبل ترفض مثل هذا التطبيق وفق **القاعدة 4.2 (الحد الأدنى من الوظائف)** في إرشادات مراجعة App Store. لهذا يُبنى التطبيق أصليًا على ملفات JSON.
